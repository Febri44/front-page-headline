# front-page-headline

One sentence summing up today's world news as a front-page headline, written to
`/output/entry.txt` by `main.ts` (Node 22). Built for the make.fun bounty
[One Sentence, One Front Page](https://make.fun/bounty/u-brisk-kestrel-93-one-sentence-one-front-page-0db596eb).

## Run

```sh
node main.ts
```

It writes the headline to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
